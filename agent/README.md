# Dorawa (도라와)

리눅스 노트북 도난 추적기. 평소엔 조용히 대기하다가, 내가 `/lost`를 보내면
주기적으로 위치·주변 와이파이·(선택) 웹캠 사진을 보고합니다. 서버가 없고, 각 사용자가
자기 채널(ntfy topic 등)을 쓰므로 개발자는 아무 데이터도 받지 않습니다.

## 알림 채널
- **ntfy** (권장): 오픈소스 푸시 알림. 보고 + 명령(/lost 등) 모두 지원. 공식 서버(ntfy.sh)
  또는 자체 서버 사용 가능.
- **디스코드 웹훅**: 보고만 받음(명령 불가). 봇 아님 — URL 하나로 설정 끝.
- 둘 다 동시에 켜면, ntfy로 명령을 받고 보고는 양쪽에 뜬다.

## 명령 (ntfy topic으로 전송)
- `/lost` — 도난 모드 켬 (주기 보고 시작)
- `/found` — 도난 모드 끔
- `/status` — 지금 1회 보고

## 설치 (리눅스)
```
sudo ./install.sh
```
설치 중 설정 마법사가 채널을 받습니다. 이후 타이머를 켭니다:
```
sudo systemctl enable --now dorawa.timer
```

## 보안 권장 (이 프로그램만으로는 부족)
- BIOS 관리자(Supervisor) 비밀번호로 USB 부팅·초기화 차단
- 디스크 암호화(LUKS) — 설정 파일의 채널 자격증명 유출 방지
- ntfy topic 이름은 추측하기 어려운 긴 문자열로 (사실상 비밀번호 역할)
