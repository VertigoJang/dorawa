# Dorawa (도라와)

리눅스/윈도우 노트북 도난 추적기. 노트북이 도난당하면 위치·주변 와이파이·
원격 촬영(사진/영상)을 자체 서버로 보고하고, 주인은 데스크톱 앱이나 웹에서 조회한다.

## 구성
- **server/** — 중앙 서버 (Flask). 계정·기기·보고 관리, 이메일 인증, 롱폴링
- **agent/** — 추적 대상 노트북에 설치되는 백그라운드 에이전트 (systemd)
- **app/** — 주인이 쓰는 데스크톱 앱 (PySide6, 리눅스/윈도우)
- (예정) mobile/ — 스마트폰 앱 (Android / iOS)

## 빠른 시작
### 서버 (클라우드 VM 등)
    cd server && sudo ./deploy.sh      # DuckDNS + HTTPS + 자동실행

### 데스크톱 앱
    cd app && ./build_linux.sh         # dist/Dorawa 생성 (더블클릭 실행)

### 에이전트 (추적 대상 노트북)
    데스크톱 앱의 '이 기기 보호' 탭에서 6자리 페어링으로 설치
    (또는 cd agent && sudo ./install.sh)

## 특징
- 자체 서버 기반 — 제3자 메신저 없음
- 이메일 인증 회원가입, 비밀번호 찾기, 중복 가입 방지
- 원격 촬영은 주인이 누를 때만 (롱폴링으로 거의 즉시), 웹캠 LED 노출 최소화
- 촬영 모드 선택: 원격 전용 / 자동 주기
